Facility Inspection App — 動画デモ

設備点検・保守記録デスクトップアプリの動作デモです。点検担当者による予定確認・点検実施と、保全管理者による実施状況確認・承認／差し戻し・運用管理を役割別に掲載しています。

点検担当者デモ ↓ 保全管理者デモ ↓ 詳細へ戻る GitHub ↗

点検担当者デモ

担当する点検予定を確認し、対象設備の点検項目を入力して、コメント・写真を含む点検結果を完了させる流れを確認できます。

保全管理者デモ

点検実施状況、異常・未実施、完了・承認待ちを確認し、結果の承認／差し戻しや管理機能へ進む流れを確認できます。

デモの流れ

  • ロール別にログイン
  • 点検予定・実施状況を確認
  • 点検項目・結果・コメントを記録
  • 必要に応じて写真を登録
  • 点検完了
  • 保全管理者が承認または差し戻し

補足

  • デスクトップアプリのためブラウザ実行デモの代わりに動画を掲載しています。
  • 掲載データ・設備情報・画像はすべてデモ用です。
  • 点検担当者と保全管理者で画面・操作を分離しています。
