設備点検・保守管理アプリ

Avalonia UI / C# / SQLiteで構築した、設備点検・保守記録向けデスクトップアプリです。
工場設備の点検業務を想定し、点検予定の作成から担当者による点検実施、チェック結果・コメント・写真の記録、保全管理者による承認／差し戻し、操作履歴の保存までを一連の業務フローとして実装しています。

実装内容

点検予定を起点に、実施・結果記録・レビュー・運用管理までを役割別画面でつなげています。

点検担当者

  • ローカルログイン、ロール別画面遷移
  • 担当点検予定カレンダー／担当点検一覧
  • 点検チェックリスト、数値・テキスト等の入力
  • 異常判定、コメント、点検写真の登録
  • 点検開始・完了と状態管理

保全管理者

  • 点検実施状況・詳細、未実施・異常一覧
  • 完了・承認待ち一覧、承認／差し戻し
  • 設備、点検表テンプレート、点検予定、担当者管理
  • 操作履歴の確認
  • SQLiteデータベースのバックアップ／復元

設計・品質

  • Avalonia UI + MVVMでViewと画面状態・Commandを分離
  • Repository / Service / ViewModelの責務分離
  • 点検予定と実施実績を分離したデータモデル
  • Domain / Service / ViewModelを中心としたxUnitテスト
  • GitHub ActionsでRestore / Build / Unit Testを自動化

業務フロー・設計

区分主な内容設計上のポイント
点検予定設備・点検表・担当者・予定日を割り当てInspectionScheduleとして「予定」を独立管理
点検実施開始、項目入力、異常判定、コメント、写真、完了Inspection / InspectionResult / InspectionPhotoとして実績を保存
レビュー保全管理者が結果を確認し、承認または差し戻し状態遷移と差し戻し理由を保持
マスタ管理設備、設置場所、点検表テンプレート、担当者点検時点の結果情報を履歴として残せる構成
運用管理操作履歴、バックアップ／復元ローカルSQLite運用を前提にトレーサビリティと保全性を確保

点検予定 → 点検実施 → 結果・写真 → 承認／差し戻し → 操作履歴、という一連の流れを画面・データ双方で追跡できる構成にしています。
